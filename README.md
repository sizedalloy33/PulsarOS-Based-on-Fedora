Welcome to PulsarOS. PulsarOS has been built using Universal Blue's image-template (https://github.com/ublue-os/image-template.git) with a base on Bazzite (https://github.com/ublue-os/bazzite.git) which is built off of Fedora. 

PulsarOS is designed to be a simple plug-and-play gaming linux distro to allow users with an interest in linux gaming to have a smooth and easy transition while also not completely locking out normal home computer uses.

PulsarOS is very much still in the early stages of development so issues are being worked on readily. If running PulsarOS please do not store sensitive data until a version is confirmed stable.
