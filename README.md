Welcome to PulsarOS. Your number one stop for simple plug-and-play gaming. PulsarOS is designed to be a lightweight plug-and-play gaming centered Linux distro to allow users interested in trying Linux gaming to smoothly transition without sacrificing basic utility for school and work. 

PulsarOS has been built using Universal Blue's image-template (https://github.com/ublue-os/image-template.git) with a base on Bazzite (https://github.com/ublue-os/bazzite.git) which is built off Fedora.

PulsarOS is an immutable operating system which means the core system is protected from accidental deletions and any system breaking updates can be rolled back to stable versions. This makes it perfect for new Linux users!

PulsarOS contains easy to use plug-and-play features such as a comfortable/semi-familiar UI (powered by KDE Plasma) and a welcome application to allow quick and easy installations of recommended applications and drivers.

PulsarOS aims to be lightweight than many other gaming centered distros and has as little bloat as possible.

PulsarOS is very much still in the early stages of development, so issues are being worked on readily. If you find issues while using the distribution, please report them in the issues section of GitHub. At this moment PulsarOS is configured for AMD machines and as such cannot guarantee reliability with Nvidia GPUs.

We are currently working on expanding our documentation to allow for easy use and setup of PulsarOS.

We are excited to have you join us in the stars.

Installing PulsarOS

	All PulsarOS installs are available through our Cloudflare page. Simply look at the latest release on GitHub to find redirect links.

 	Install an image (commonly the anaconda-iso) and place it onto a usb drive. When creating a bootable usb it is commonly recommended to format it with Ventoy (https://www.ventoy.net/en/index.html) before downloading an iso file to it.

	Once you have your bootable usb, plug it into the computer you with to install it on and boot up the computer. Many computers allow you to use F12 to select your boot drive during the boot up sequence. Select your usb and follow the instructions of the installer to set up your OS.

	Once setup you will be greeted by the PulsarOS welcome app (which opens every boot and can also be found through your app launcher) which will suggest programs you may want to install for the very best experience.

Live Boot PulsarOS

	Install the live-boot iso file from the latest release

	Create a bootable USB. When creating a bootable usb it is commonly recommended to format it with Ventoy (https://www.ventoy.net/en/index.html) before downloading an iso file to it.

	Plug your bootable USB into the computer which you wish to test PulsarOS on. When turning on the computer select the USB as your boot drive (may need to use F12 to bring up the setting to change boot drive).

	When booting into your USB you will see a Ventoy page. Press ENTER. On the following screen use arrow keys to navigate to the GRUB2 option. Press ENTER. You will then see an option labeled PulsarOS. Press ENTER once more to boot the OS.

	Live-boot will not override your other drives.

	There is no password set for the Live-Boot profile. Leave the password blank.

	Welcome to your live session of PulsarOS
